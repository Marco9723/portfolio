Projects

LSTM Gear

LSTM GEAR is a new plugin that emulates electric guitar effects using neural models in C++ through blackbox modelling of analog pedals. This work also contains a report on the new and promising RTNeural library for neural models implemented in C++.

GitHub YouTube

MuQ-BTC

MuQ-BTC is an Automatic Chord Recognition (ACR) model developed as part of a research collaboration with Great Bay University (Dongguan, China), under the supervision of Dr. Yaolong Ju, Assistant Professor. The model was also submitted to the MIREX 2026 challenge, where it demonstrated excellent results and confirmed the effectiveness of the newly proposed ACR pipeline.

MIREX Interactive demo

Kinetic Sonic Performer

“Kinetic Sonic Performer” is a project built on a full-fledged model designed to foster continuous interaction between the user and the system. It thrives on learning and adaptation to ensure an engaging experience. The fundamental idea is to enable individuals to generate music by moving their bodies, where artists craft unique interactive systems.

GitHub Report

PolyLooper

Polylooper is a web app to help the user in the creation of polyrhythms.

GitHub YouTube

Lightweight Publish–Subscribe Protocol for TinyOS

Designed and implemented a lightweight publish–subscribe communication protocol inspired by MQTT in TinyOS. The protocol was evaluated through simulations on a star-shaped wireless network comprising eight client nodes connected to a PAN coordinator, which served as the central broker for message distribution. The project focused on implementing an efficient messaging architecture for resource-constrained wireless sensor networks and validating its operation in a simulated environment.

Hooktheory_to_kern_converter

The goal of this script is to convert songs from the HookTheory dataset into the corresponding **kern file. For melodies this is done by using MIDI notation as reference. The code permits to select a song from the dataset and convert it in the corresponding **kern format.
